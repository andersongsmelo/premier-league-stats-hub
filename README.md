# Premier League Stats Hub

Web application built with Next.js, React, and Tailwind CSS for the **CPAN 144 – Advanced Front-End Programming** course.

## Phase 1 Overview

This phase establishes the foundational project structure, component hierarchy, client-side state management, routing, and responsive layout using initial placeholder data.

### Implemented Structure & Features

- **Layout & Navigation:** Persistent header navigation and footer across the application.
- **Pages & Routing:** Navigation across primary views, including standings, club details, and informational content.
- **Components & State:** Reusable components (`SearchBar`, `StandingsTable`, `Navbar`, `Footer`) using React state, props, and lifted state.
- **Styling:** Responsive layout built with Tailwind CSS for desktop and mobile screens.

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```
